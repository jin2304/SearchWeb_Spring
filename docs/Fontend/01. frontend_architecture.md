# SearchWeb Frontend Architecture

SearchWeb 프론트엔드는 현대적인 웹 기술 스택을 활용하여 프리미엄한 사용자 경험과 높은 유지보수성을 확보하는 것을 목표로 합니다.

## 🛠 Tech Stack & Rationale (기술 스택 선정 이유)

| 기술 스택 | 채택 이유 | 기대 효과 |
| :--- | :--- | :--- |
| **Next.js 15 (App Router)** | React 19 지원 및 서버 컴포넌트(RSC) 최적화 필요 | 초기 로딩 속도 향상 및 SEO 최적화 |
| **Zustand** | Redux 대비 매우 가벼운 보일러플레이트 및 직관적인 API | 링크/폴더/UI의 복잡한 전역 상태를 효율적으로 관리 |
| **TanStack Query v5** | 서버 상태(Server State) 관리와 캐싱의 표준 | API 연동의 선언적 처리 및 로딩/에러 상태 관리 자동화 |
| **Tailwind CSS v4** | 유틸리티 우선 스타일링 및 최신 CSS 기능 활용 | 디자인 시스템 구축 속도 향상 및 유지보수 용이 |
| **shadcn/ui** | 검증된 접근성과 고난도 UI 프리미티브(Dialog, Popover 등) 제공 | 서비스의 'Premium Purple' 스타일을 빠르고 일관되게 구현 |
| **TypeScript (Strict)** | 엄격한 타입 체크를 통한 런타임 에러 방지 | 코드 안정성 확보 및 대규모 협업 효율성 증대 |
| **Axios** | 인터셉터 및 커스텀 인스턴스 설정의 유연함 | 백엔드 공통 응답 규격(Envelope) 처리에 최적화 |

## 📁 Directory Structure (프로젝트 구조)

```text
frontend/
├── src/
│   ├── app/                # Next.js App Router (Pages & Layouts)
│   │   ├── login/          # 구글 소셜 로그인 연동 페이지
│   │   ├── my-links/       # 핵심 기능: 대시보드 메인 뷰
│   │   └── layout.tsx      # Root Layout (Theme & Provider)
│   ├── components/
│   │   ├── ui/             # shadcn/ui 기반 아토믹 컴포넌트
│   │   ├── layout/         # AppLayout, Sidebar, Header
│   │   ├── my-links/       # 대시보드 전용 (FolderCard, RightPanel)
│   │   ├── dialogs/        # 기능별 모달 (CreateFolder, SaveLink)
│   │   └── providers/      # Context (QueryProvider 등)
│   ├── lib/
│   │   ├── store/          # Zustand 스토어 (linkStore, folderStore, uiStore)
│   │   ├── api/            # API 클라이언트 및 엔드포인트 모듈
│   │   ├── types/          # 공통 타입 및 인터페이스
│   │   └── utils.ts        # 클래스 병합 유틸리티 함수
│   └── public/             # 브랜드 에셋 및 정적 아이콘
```

## ✅ 지금까지 완료된 작업 요약

### 1. 프로젝트 기반 및 환경 설계
- **초기화**: Next.js 15 + React 19 + TypeScript Strict 모드 설정
- **인프라**: pnpm 워크스페이스 및 배포 최적화 설정
- **테마**: Tailwind v4를 활용한 프리미엄 보라색(#7c3aed, #a78bfa) 및 글래스모피즘 디자인 시스템 구축

### 2. 핵심 로직 및 데이터 흐름
- **상태 관리**: Zustand를 이용한 도메인 기반 전역 상태 설계
- **데이터 페칭**: TanStack Query v5 + Axios 기반 API 연동 모듈 및 커스텀 훅(`useFolders` 등) 구현
- **응답 규격**: 백엔드 공통 Response (code, message, data) 규정 및 인터페이스 설계

### 3. 주요 UI 및 레이아웃
- **Layout**: 고정 사이드바 및 반응형 헤더를 포함한 `AppLayout` 완성
- **UI Components**: shadcn/ui 기반 고품질 컴포넌트 커스터마이징 추가
- **View**: 메인 랜딩, 소셜 로그인 인터페이스, 마이링크 대시보드 조립 완료

## 🚀 실제 프론트 동작 명령어 (pnpm)

```bash
# 프론트엔드 작업 경로 진입
cd frontend

# 개발 서버 실행 (Turbopack 적용)
pnpm dev

# 배포용 빌드 및 실행
pnpm build
pnpm start

# 코드 품질 검사
pnpm exec tsc --noEmit  # 타입 체크
pnpm lint               # 코드 스타일 및 린트
```

## ⚠️ 주의사항

2. **반응형 설계**: `my-links` 페이지의 그리드 레이아웃(5열) 유지 시 뷰포트 크기를 고려하십시오.
3. **스타일 일관성**: 프리미엄 보라색 그라디언트 테마의 디자인 톤앤매너를 준수해야 합니다.
