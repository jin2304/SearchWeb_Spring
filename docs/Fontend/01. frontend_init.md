# SearchWeb 프론트엔드 초기 설정 가이드

## ✅ 완료된 작업

### 1. 프로젝트 구조 설정
- ✅ Next.js 15 + React 19 프로젝트 초기화
- ✅ TypeScript strict 모드 설정
- ✅ App Router 기반 디렉토리 구조
- ✅ Tailwind CSS v4 통합

### 2. 상태 관리 구축
- ✅ **Zustand 스토어 3개 구현**
  - `linkStore`: 링크 상태 관리 (필터, 정렬, 검색)
  - `folderStore`: 폴더 상태 관리 (CRUD, 트리 구조)
  - `uiStore`: UI 상태 관리 (다이얼로그, 사이드바)

### 3. API 클라이언트 및 데이터 페칭
- ✅ **TanStack Query (React Query) v5 설정**
- ✅ **API 클라이언트 구현** (`lib/utils/api.ts`)
  - REST API 지원
  - 자동 타임아웃
  - 에러 처리
  
- ✅ **TanStack Query 훅 구현**
  - Links: `useLinks`, `useLink`, `useCreateLink`, `useUpdateLink`, `useDeleteLink`
  - Folders: `useFolders`, `useFolder`, `useCreateFolder`, `useUpdateFolder`, `useDeleteFolder`
  - Tags: `useTags`, `useTag`

### 4. 기본 컴포넌트 및 레이아웃
- ✅ **레이아웃 컴포넌트**
  - Sidebar: 좌측 네비게이션 (로고, 프로필, 메뉴, 액션 버튼)
  - Header: 상단 헤더 (검색, 알림, 설정)
  
- ✅ **대시보드 레이아웃** (`(dashboard)/layout.tsx`)
  - QueryClientProvider 통합
  - 반응형 디자인

- ✅ **My Links 페이지** (`(dashboard)/my-links/page.tsx`)
  - 링크 목록 표시
  - 로딩 및 에러 상태
  - 그리드 레이아웃

### 5. 타입 정의
- ✅ **TypeScript 타입** (`src/types/index.ts`)
  - Link, Folder, Tag, FilterState
  - ApiResponse, PaginatedResponse

### 6. 스타일링
- ✅ **Tailwind CSS v4 설정**
  - 커스텀 색상 토큰 (Purple, Blue, Gray)
  - 그라디언트 유틸리티
  - 그림자 유틸리티
  - 글로벌 CSS (`src/styles/globals.css`)

### 7. 개발 환경 설정
- ✅ **환경 변수** (`.env.local`, `.env.example`)
- ✅ **ESLint/Prettier 설정** (계획 중)
- ✅ **TypeScript 설정** (strict mode)
- ✅ **Next.js 설정**

## ⚠️ 주의사항

1. **Tailwind v4**: 이전 버전과 구문이 다릅니다. CSS 변수로 색상 정의됩니다.
2. **React 19**: 새로운 React 기능을 활용할 수 있습니다.
3. **Next.js 15**: App Router 기반 최신 구조입니다.
4. **Turbopack**: 빌드 속도가 매우 빠릅니다.

## 🆘 문제 해결

### "Cannot find module '@tailwindcss/postcss'"
```bash
npm install @tailwindcss/postcss --legacy-peer-deps
```

### "Module '..' was resolved but '--jsx' is not set"
- `tsconfig.json`에서 `"jsx": "preserve"` 설정 확인

### Peer dependency 충돌
```bash
npm install --legacy-peer-deps
```
